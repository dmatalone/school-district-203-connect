ConnectCast – Vivi-style HTML demo

Files:
- index.html: start screen
- receiver.html: open on the computer/display
- remote.html: open on the phone

How to use:
1. Host all three files on the same HTTPS website, such as GitHub Pages.
2. On the computer, open receiver.html.
3. The computer displays a 6-digit code.
4. On the phone, open remote.html.
5. Enter the 6-digit code and tap Connect.
6. Send messages, websites, or images to the computer.

Important:
- This is a browser-based remote/presentation demo, not a true HDMI receiver.
- It uses PeerJS's public signaling service. For production, use your own signaling server.
- Some websites block iframe embedding.
